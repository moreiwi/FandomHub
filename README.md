# FandomHub - интерактивный каталог популярных медиафраншиз

**FandomHub** - это учебный веб-проект, представляющий собой интерактивный каталог популярных медиафраншиз.

Проект разрабатывается в рамках учебной практики студетами 2 курса колледжа НКЭиВТ. Сайт предназначен для просмотра информации о различных медиафраншизах, их категориях, жанрах и особенностях.

## Цель проекта

Цель проекта - разработать адаптивный веб-сайт на HTML, CSS, JavaScript, который позволит вользователю просматривать каталог популярных медиафраншиз, использовать поиск, фильтрацию, сортировку.
